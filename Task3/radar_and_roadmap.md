# Roadmap

![Roadmap](roadmap.png)

## Этапы:

| № Этапа | Наименование                                    | Ожидаемые результаты                                           | Ответственные команды                | Ресурсы                                             | Бизнес-обоснование                                                                                                                      |
| ------- | ----------------------------------------------- | -------------------------------------------------------------- | ------------------------------------ | --------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| 1       | Анализ текущего состояния и определение доменов | Карта доменов с четкими границами                              | Архитекторы, бизнес-аналитики        | инструменты документирования                        | Четкие домены ускоряют принятие решений о развитии<br>Готовность к подключению новых бизнесов<br>Есть ответственные за данные и сервисы |
| 2       | Развертывание облачной платформы                | Готовая облачная инфраструктура                                | Инфраструктурная команда             | Terraform, Cloud-Платформа (например, яндекс cloud) | Снижение затрат<br>Гибкое выделение ресурсов под нагрузку<br>Повышение доступности сервисов                                             |
| 3       | Миграция аналитических данных в Lakehouse       | Data Lakehouse с аналитическими данными                        | команда data-инженеров               | Spark, Airflow                                      | Отчеты формируются за минуты вместо часов<br>Актуальные данные для принятия решений<br>Масштабируемость                                 |
| 4       | Запуск MVP портала самообслуживания             | Работающий портал самообслуживания                             | Инфраструктурная команда             | Dremio                                              | Прямой доступ к данным без посредников<br>Актуальные данные                                                                             |
| 5       | Внедрение Apache Kafka                          | Работающая событийная шина                                     | Инфраструктурная команда             | Kafka                                               | Упрощение интеграций<br>Масштабирование - Легкое подключение новых систем<br>Надежность                                                 |
| 6       | Пилот Data Mesh в финтех-домене                 | Первый работающий Data Product                                 | Финтех-команда + Data Mesh Core Team | DataHub, Apache Kafka, мониторинг                   | Самостоятельный доступ к финансовым данным<br>Пример для других доменов                                                                 |
| 7       | Расширение Data Mesh на все домены              | Полная Data Mesh архитектура, Самостоятельное развитие доменов | Domain Teams + Data Mesh Core Team   | DataHub, Apache Kafka, мониторинг                   | Независимое развитие подразделений<br>Децентрализованное управление данными<br>Эффективное использование ресурсов                       |
