# Деление на домены:

1. Клиника/медицина	
   
   Владеет первичными медицинскими сущностями: пациенты, визиты, диагнозы, назначения, результаты анализов и процедур. Это источник истины для клинической деятельности.

2. Финансы	
   
   Владеет всеми финансовыми транзакциями: оплаты услуг, страховые выплаты, внутренние расчеты между подразделениями, кассовые операции. Отвечает за финансовую отчетность и интеграцию с финтех-сервисами.

3. ИИ-сервисы	
   
   Не создает первичных данных, но строит на их основе высокоуровневые продукты: прогнозные модели, системы рекомендаций, предиктивную аналитику оборудования. Потребляет обогащенные данные из других доменов.

4. Маркетинг и партнёры
   
   Владеет данными о взаимодействиях (CRM, рекламные кампании, лояльность) и управляет интеграцией с внешними партнерами (фармацевтика – данные о лекарствах, электроника — данные с устройств). Агрегирует данные для сквозной аналитики по клиенту.

# Преимущества для бизнеса:

- Ускорение вывода продуктов: Команды доменов могут независимо развивать свои продукты. Для запуска финтех-сервиса не нужно ждать очереди на изменение центрального DWH. Это сокращает time-to-market.

- Снижение нагрузки на унаследованный DWH: DWH становится одним из потребителей данных, а не единой точкой консолидации. Пиковые нагрузки изолированы в рамках доменов. Решается исходная техническая проблема.

- Повышение надежности и ответственности: За качество финансовой отчетности отвечает финансовый домен, за клинические данные — медицинский. Снижаются операционные риски и риски несоответствия регуляторным требованиям.

- Поддержка инноваций: Создается экосистема данных, где новые сервисы (ИИ, партнерские интеграции) могут легко подключаться к готовым data-продуктам.
